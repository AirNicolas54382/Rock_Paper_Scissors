## 📖 About The Project

This is a lightweight desktop application developed in Java. It brings the traditional "Rock, Paper, Scissors" game to a visual format using standard Java GUI libraries. The player competes against a computer opponent that makes randomized decisions, while the application keeps track of the ongoing score across multiple rounds.

### ✨ Key Features
*   **Graphical Interface:** Interactive pixel-art buttons for selecting moves instead of a text-based console input.
*   **Opponent AI:** The computer opponent selects its moves using randomized logic.
*   **Dynamic Score Tracking:** The game calculates win/loss/draw conditions and updates the score persistently (e.g., `1:0`) across rounds.
*   **Game Loop:** A built-in "Return" function allows players to quickly jump back into the next round without restarting the application.

## ⚙️ Installation & Execution

### Prerequisites
Make sure you have the **Java Development Kit (JDK)** installed on your machine (version 8 or higher is recommended).

### Running in IntelliJ IDEA
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/AirNicolas54382/Rock_Paper_Scissors
    ```
    *(Alternatively, download the `.zip` file and extract it).*
2.  Launch **IntelliJ IDEA**.
3.  Click on **Open** and select the extracted project folder.
4.  Allow the IDE a moment to index the files and configure the Java SDK.
5.  In the *Project Explorer* (left panel), navigate to your `src` folder and locate the main class file (e.g., `Main.java`).
6.  Right-click the file and select **▶ Run 'Main.main()'**.
